# Lecture 2: Gradio Homography Tool

Инструмент на Python + Gradio для ручной разметки соответствующих точек на:

- фото футбольного поля;
- макете футбольного поля.

После разметки считает гомографию и показывает третье изображение: фото поля после применения гомографии к координатам макета.

## Запуск

```bash
cd lecture_2
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

После запуска откройте локальный URL Gradio (обычно `http://127.0.0.1:7860`).

## Как пользоваться

1. Загрузите фото поля (слева) и макет поля (по центру).
2. Кликайте по соответствующим точкам на обоих изображениях в одинаковом порядке.
3. Нажмите `Построить гомографию`.
4. Справа появится изображение, полученное после `warpPerspective`.

## Примечания

- Нужно минимум 4 пары точек.
- Лучше выбирать точки по всему полю (углы, центр, пересечения линий).
- Если количество точек не совпадает или точки вырождены, гомография не построится.
